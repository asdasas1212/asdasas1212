# Profile artwork

Self-hosted artwork for the hkx / asdasas1212 profile.

Run `python3 assets/generate_profile.py` with Pillow and NumPy to rebuild the banner and project cards.

`profile-showcase.svg` is the main profile image. It is a hand-authored, self-contained
SVG with an 18-second CSS animation loop: perception, grounding, then planning and
robot movement. Edit this SVG directly; it is independent of the Python generator.
The scene and outputs are illustrative presets, not live model inference.
